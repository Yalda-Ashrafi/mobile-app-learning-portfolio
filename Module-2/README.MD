
##  Kotlin Fundamentals Practice

###  Overview
This project demonstrates key **Kotlin programming fundamentals** through practical examples integrated into an Android app using **Jetpack Compose**.  
Each section covers a core concept — from conditionals and functions to classes, inheritance, and UI composition — presented in a visually structured layout.

---

###  Features
-  **Mobile Notifications** – Conditional logic and string interpolation  
-  **Movie Ticket Price** – `when` expressions and function parameters  
-  **Temperature Converter** – Lambda expressions and higher‑order functions  
-  **Song Catalog** – Class properties and computed getters  
-  **Internet Profile** – Nullable types and object references  
-  **Foldable Phone Simulation** – Inheritance and method overriding  
-  **Special Auction** – Null‑safety and Elvis operator usage

###  How to Run
```bash
git clone https://github.com/Yalda-Ashrafi/KotlinFundamentalsPractice.git
cd KotlinFundamentalsPractice
```
Open in **Android Studio**, then:
1. Sync Gradle.
2. Run the app on an emulator or physical device.
3. Explore each section interactively.
