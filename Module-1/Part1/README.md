
##  Kotlin Practice — Module 1 Examples

### Overview
This section of the project demonstrates Kotlin fundamentals through simple, practical examples created in IntelliJ IDEA. Each file builds on the previous one to strengthen understanding of variables, functions, and logic flow.

---

###  Example 1 — Variables and Keywords
**Concepts covered:**
- `val` for constants  
- `var` for mutable values  
- Basic `println()` usage  

**Code summary:**
Shows how to declare variables and print messages explaining when to use `val` vs `var`.

**Output:**
```
![image alt]()
![image alt]()
Use the val keyword when the value doesn't change.
Use the var keyword when the value can change.
When you define a function, you define the parameters that can be passed to it.

```

**Concepts covered:**
